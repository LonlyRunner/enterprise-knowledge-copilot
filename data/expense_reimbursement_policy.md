# 星云科技有限公司费用报销管理细则

**文件编号**：XY-FIN-002　　**版本**：V2.0　　**生效日期**：2026-02-01  
**责任部门**：财务部

## 一、报销基本要求

1. 报销必须使用企业费用管理系统提交，纸质单据作为必要附件留存。
2. 发票抬头必须为“星云科技有限公司”，并包含统一社会信用代码；个人抬头、金额涂改或无法验证真伪的票据不得报销。
3. 员工应在费用发生后 30 个自然日内提交报销。跨月报销须说明原因，超过 90 个自然日的原则上不予受理。
4. 同一笔费用不得重复报销，不得拆分金额规避审批权限。

## 二、审批权限

| 单笔含税金额 | 审批流程 |
| --- | --- |
| 2,000 元及以下 | 员工 → 直属主管 |
| 2,000 元以上至 10,000 元 | 员工 → 直属主管 → 部门负责人 |
| 10,000 元以上至 20,000 元 | 员工 → 直属主管 → 部门负责人 → 财务负责人 |
| 20,000 元以上 | 员工 → 直属主管 → 部门负责人 → 财务负责人 → 分管副总 |
| 100,000 元以上 | 在上述流程基础上增加总经理审批 |

## 三、办公及业务费用

1. 办公用品由行政部统一采购。紧急采购单笔不超过 500 元的，可由部门负责人审批后报销；超过 500 元应先走采购申请。
2. 客户接待费用应提前提交接待申请，说明客户名称、来访人数、接待事由和预算。工作日午餐标准为每人不超过 150 元，晚餐标准为每人不超过 300 元。
3. 业务招待不得购买烟酒作为礼品，不得向政府工作人员或客户提供现金、购物卡及其他可能影响公正决策的利益。
4. 员工购买软件订阅、云服务或 API 服务前，必须由 IT 部门确认安全性，由财务部确认预算归属。

## 四、报销办理

1. 员工在系统填写费用类型、发生日期、金额、成本中心和项目编号，上传发票及支付凭证。
2. 直属主管应在 3 个工作日内完成业务真实性审核；财务部收到完整单据后，在 5 个工作日内完成财务审核。
3. 审核通过后，财务部在下一批付款日统一支付。银行卡信息发生变化时，应提前在员工系统更新并完成身份验证。

## 五、特殊情况

1. 发票遗失时，须提供电子发票、付款记录和情况说明；单笔金额超过 2,000 元的还需部门负责人签字确认。
2. 因公司活动产生的集体费用，可以由经办人统一报销，但必须附参与人员名单和活动审批记录。
