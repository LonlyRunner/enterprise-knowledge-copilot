星云科技有限公司
信息安全管理规范

文档编号：SEC-POLICY-2026-003
版本：V3.0


第一章 密码管理

公司员工账号密码不得与个人互联网账号使用相同密码。

核心业务系统密码至少每90天修改一次。

员工不得通过聊天软件向他人发送公司账号密码。


第二章 API Key 管理

API Key、Access Token、Secret Key 等认证凭证属于公司敏感信息。

认证凭证不得写入公开代码仓库。

生产环境密钥应统一存储在公司批准的密钥管理系统中。


第三章 AI 开发安全

开发人员不得向未经批准的外部AI模型发送：

客户隐私信息；

生产数据库密码；

API Key；

完整的公司源代码；

未公开的财务数据。

开发人员使用AI生成代码后，
必须由开发人员本人进行代码审查和安全检查。
