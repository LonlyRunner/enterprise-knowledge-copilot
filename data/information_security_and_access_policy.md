# 星云科技有限公司信息安全与访问控制制度

**文件编号**：XY-SEC-006　　**版本**：V2.0　　**生效日期**：2026-01-20  
**责任部门**：信息安全委员会、IT 部门、人力资源部

## 一、账号和认证

1. 公司系统必须使用个人账号，禁止共用账号。账号密码不得与个人互联网账号相同。
2. 生产系统、代码仓库、云平台、财务系统和远程接入必须启用多因素认证（MFA）。
3. 密码长度至少 12 位，必须同时包含字母、数字和特殊字符；连续 5 次认证失败后锁定 15 分钟。
4. API Key、Access Token、Secret Key、数据库密码和私钥均属于公司敏感凭证，禁止写入源代码、工单、即时通讯群或个人网盘。

## 二、权限申请与回收

1. 权限遵循最小权限原则，员工只获得完成当前工作所需的系统和数据访问权。
2. 普通业务权限由直属主管审批，生产权限由系统负责人和 IT 安全负责人共同审批；临时权限最长有效期为 7 天。
3. 员工转岗时，原部门权限应在 1 个工作日内回收，新岗位权限重新申请。
4. 员工离职时，人力资源部发起离职通知，IT 部门应在最后工作日 18:00 前禁用账号、撤销令牌和回收设备。
5. IT 部门每季度对高权限账号进行一次复核，发现不再需要的权限应立即移除。

## 三、数据处理

1. 客户隐私、合同、财务数据、未公开经营数据和完整公司源代码属于高敏感数据。
2. 未经批准，不得将高敏感数据提交给外部 AI 服务、公共代码仓库、个人邮箱或个人网盘。
3. 测试环境使用生产数据前必须完成脱敏，导出的数据文件应设置有效期并在使用结束后删除。
4. 发现疑似数据泄露、钓鱼邮件、恶意软件或凭证泄露时，应立即联系信息安全值班人员，不得自行删除证据。

## 四、安全事件分级

1. 一级事件：涉及客户数据、生产密钥或大范围系统入侵，15 分钟内上报。
2. 二级事件：单个账号被盗、恶意软件感染或内部敏感资料误发，30 分钟内上报。
3. 三级事件：可疑邮件、弱密码或一般安全违规，在当日工单中登记处理。
